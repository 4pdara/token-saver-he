# token-saver-he

תוסף דפדפן שמנסה לתרגם הודעות מעברית לאנגלית לפני שליחתן באתרי צ׳אט, כדי לבדוק אפשרות לצמצום מספר טוקני הקלט. התוסף מציג בועה נגררת להפעלה ולכיבוי, ומשתמש בשירות התרגום של Google ללא מפתח API בקוד הנוכחי.

**החיסכון בטוקנים אינו מובטח.** התוסף אינו מודד טוקנים או עלויות. מספר הטוקנים תלוי בטקסט ובמודל המקבל; התרגום עצמו אינו מפעיל מודל שפה דרך חשבון ה־AI שלכם.

## איפה התוסף פועל?

ההפעלה מוגדרת ב־`manifest.json` עבור הכתובות הבאות בלבד:

- `https://claude.ai/*`
- `https://chatgpt.com/*`
- `https://chat.openai.com/*`

זהו תוסף לדפדפן התומך בתוספי Chromium וב־Manifest V3, כגון Chrome או Edge. הוא אינו משתלב ביישומי הדסקטופ של Claude או Codex, ולא הוגדרה בו תמיכה ייעודית במסכי Codex. גם באתרים הנתמכים, שינוי במבנה שדה ההקלדה או כפתור השליחה עלול להשפיע על פעולתו.

## התקנה ידנית

1. הורידו את קובץ **token-saver-he-v4.0.1.zip** מ־[עמוד הגרסה](https://github.com/4pdara/token-saver-he/releases/tag/v4.0.1) וחלצו אותו לתיקייה קבועה במחשב.
2. ב־Chrome פתחו `chrome://extensions` (ב־Edge: `edge://extensions`).
3. הפעילו **מצב מפתח / Developer mode**.
4. לחצו על **טעינת תוסף לא ארוז / Load unpacked**.
5. בחרו בתיקייה שחילצתם, שבה נמצא הקובץ `manifest.json`.
6. פתחו או רעננו את אתר הצ׳אט הנתמך. הבועה אמורה להופיע בפינה הימנית העליונה.

אין צורך בהתקנת חבילות, בתהליך build או בהגדרת מפתח API. אין למחוק את התיקייה שממנה נטען התוסף. לאחר שינוי בקבצים, לחצו על רענון התוסף בעמוד התוספים ורעננו גם את אתר הצ׳אט.

## שימוש

- **נקודה ירוקה:** התרגום פעיל. זו גם ברירת המחדל בהתקנה הראשונה.
- **נקודה אפורה:** התרגום כבוי.
- לחיצה על הבועה מפעילה או מכבה את התרגום. ההגדרה נשמרת מקומית ומשותפת ללשוניות הנתמכות באותו פרופיל דפדפן.
- גרירת הבועה מזיזה אותה; המיקום נשמר מקומית ומשוחזר בטעינת עמודים בהמשך.
- כתבו הודעה בעברית ולחצו **Enter** או על **חץ השליחה**. התוסף מנסה לתרגם אותה, להחליף את הטקסט בשדה ולשלוח את התרגום באנגלית.
- **Shift+Enter** אינו מפעיל את התרגום ומאפשר לשדה הצ׳אט לטפל בירידת שורה כרגיל.
- לחיצות נוספות על חץ השליחה או על Enter בזמן התרגום נחסמות כדי למנוע שליחה כפולה. אם שיניתם את הטיוטה בזמן התרגום, הטקסט החדש נשמר ואינו נשלח אוטומטית.

צבעי הבועה מותאמים אוטומטית להעדפת המצב הבהיר או הכהה של המערכת. חלון התוסף שנפתח מסרגל הדפדפן מציג הסבר קצר; ההפעלה והכיבוי מתבצעים דרך הבועה שבעמוד.

## איך זה עובד בקוד?

1. `content.js` ו־`styles.css` נטענים בעמודים המוגדרים ב־`manifest.json`.
2. הסקריפט מאזין ללחיצה על Enter בתוך שדה ההודעה (ללא Shift ומחוץ למצב הרכבת תווים), ללחיצה על כפתור שליחה מזוהה ולשליחת טופס ההודעה, כאשר התרגום פעיל.
3. הוא מאתר שדה `contenteditable` או `textarea`. הטקסט נחשב מועמד לתרגום אם אורכו גדול משלושה תווים ויותר מ־22% מתוויו נמצאים בטווח Unicode העברי `U+0590–U+05FF`. הודעות מעורבות עם מעט עברית עשויות להישלח ללא תרגום.
4. לפני התרגום, הסקריפט מנסה לשמר בלוקי קוד המסומנים בשלושה backticks, קוד בתוך backticks בודדים וקישורי HTTP/HTTPS באמצעות מצייני מקום.
5. הטקסט המעובד מחולק למקטעים של עד 800 יחידות מחרוזת JavaScript, ונשלח בבקשות GET ל־`https://translate.googleapis.com/translate_a/single` עם זיהוי שפת מקור אוטומטי ויעד אנגלית.
6. התשובות מחוברות, מצייני המקום מוחלפים בתוכן המקורי, והתרגום מוכנס לשדה ההודעה.
7. הסקריפט מפעיל כפתור שליחה מזוהה פעם אחת. אם לא נמצא כפתור, הוא משתמש בשליחת טופס ההודעה או מדמה Enter, לפי מבנה העמוד. הצלחת השליחה תלויה בממשק האתר ובאופן שבו הוא מטפל באירועים אלה.

אם מתרחשת שגיאת תרגום לפני החלפת הטקסט, ההודעה המקורית נשארת בשדה והשגיאה נרשמת בקונסולת הדפדפן. אין כרגע הודעת שגיאה ייעודית בממשק.

## פרטיות והרשאות

**כאשר התרגום מופעל, הטקסט המיועד לתרגום נשלח לשירות חיצוני של Google.** מצייני המקום נועדו לשמר קוד וקישורים במהלך התרגום; הם אינם מסנן מידע רגיש. יתר הטקסט נשלח לגוגל, ולכן יש לכבות את התרגום לפני שליחת מידע שאינכם רוצים להעביר לשירות הזה.

| הרשאה | שימוש בקוד |
| --- | --- |
| `storage` | שמירת מצב ההפעלה (`enabled`) ומיקום הבועה (`bubblePos`) ב־`chrome.storage.local` |
| `https://translate.googleapis.com/*` | גישה לכתובת שירות התרגום |
| `content_scripts.matches` | הזרקת הבועה וסקריפט התרגום באתרי הצ׳אט המפורטים לעיל |

בקוד הנוכחי אין שרת משלכם, מערכת אנליטיקה או שמירת היסטוריית הודעות. שתי ההגדרות המקומיות הן מצב ההפעלה ומיקום הבועה; טקסט ההודעה מוחזק זמנית בזיכרון לצורך התרגום.

## מגבלות ובדיקת חיסכון

- נקודת הקצה של Google משמשת כאן ללא מפתח API וללא התחייבות זמינות בקוד. שינויים בשירות, חסימת בקשות, מגבלות קצב או מגבלות דפדפן עלולים לגרום לכשל.
- התרגום עלול לשנות משמעות, ניסוח או מונחים מקצועיים. הקוד שולח את התרגום אוטומטית ללא שלב אישור נוסף.
- שימור הקוד והקישורים מבוסס על דפוסים פשוטים; הוא עלול להיכשל אם שירות התרגום משנה את מצייני המקום. חלוקת המקטעים גם אינה מתחשבת בגבולות משפטים.
- אין תמיכה מלאה בכל שדות הקלט, צירופי המקשים או ממשקי השליחה. זיהוי כפתור השליחה מבוסס על מזהה הכפתור, תווית שליחה באנגלית או בעברית, או כפתור שליחת טופס ההודעה; שינוי במבנה האתר עשוי לדרוש התאמה.
- ההודעות הקודמות בשיחה, קבצים, הוראות מערכת ותשובות המודל אינם מתורגמים באמצעות התוסף.
- אין בתוסף מונה טוקנים. כדי לבדוק חיסכון, השוו את ההודעה המקורית ואת התרגום באמצעות אותו tokenizer של המודל או נתוני שימוש בפועל. מספר תווים לבדו אינו מדד לטוקנים, ושינוי בטוקני קלט אינו מבטיח שינוי מקביל בעלות או במגבלת השימוש במנוי.

## קובצי הפרויקט

| קובץ | תפקיד |
| --- | --- |
| `manifest.json` | שם התוסף, גרסה, הרשאות, אתרים נתמכים והגדרת החלון |
| `content.js` | בועה נגררת, שמירת הגדרות, זיהוי עברית, תרגום וניסיון שליחה |
| `styles.css` | עיצוב הבועה, מצבי הפעלה והתאמה למצב בהיר וכהה |
| `popup.html` | חלון ההסבר של התוסף |
| `popup.js` | סקריפט עזר להצגת מצב; אינו מקושר ל־`popup.html` בגרסה הנוכחית |
| `README.md` | התקנה, שימוש, אופן הפעולה והמגבלות |

הפרויקט מבוסס על קובצי הזיפ `he_en_bubble_light_draggable.zip`, גרסה `4.0.0`. שם התוסף עודכן ל־`token-saver-he`; מזהי ה־DOM ומפתחות האחסון הפנימיים נשארו כפי שהיו.

## גרסה 4.0.1 ובדיקות פיתוח

נוספה הפעלת תרגום גם מחץ השליחה ומשליחת טופס ההודעה, אוחד מסלול השליחה כדי למנוע הפעלה כפולה, ונוספה הגנה על טיוטה שנערכה בזמן התרגום.

להרצת בדיקות הדפדפן:

```sh
npm ci
npx playwright install chromium
npm test
```

הבדיקות טוענות את התוסף עצמו ב־Chromium ומשתמשות בעמודי בדיקה מקומיים ובתשובות תרגום מדומות. הן אינן שולחות הודעות לשירותי הצ׳אט ואינן מוכיחות תאימות מלאה לממשקי האתרים החיים או לזמינות Google.
